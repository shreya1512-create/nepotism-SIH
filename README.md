#Team Nepotism
📌 Problem & Solution

* **The Problem:** Eligible SC beneficiaries struggle to identify suitable concessional loan schemes and locate the correct local Channel Partner among over 100 options, causing application delays and misrouted funds. **Sahay AI** solves this with a multi-lingual platform featuring smart scheme recommendations, instant EMI calculations, and geo-spatial partner routing to streamline financial aid.
* **Our Solution:** **Sahay AI** eliminates manual fragmentation and application delays through an integrated, three-pillar workflow:

* **Smart AI Recommendation Engine:** Takes basic user inputs (income, project cost, education) and instantly maps them to the exact concessional loan or scheme using dynamic rule matching, eliminating offline confusion.
* **Automated Financial Calculator:** Provides real-time EMI, interest rate (6.5%–15%), and moratorium period breakdowns tailored to specific scheme limits, giving users total financial clarity before applying.
* **Geo-Spatial Partner Routing:** Uses location services and real-time eligibility checks to route users to their nearest active Channel Partner (SCA, Bank, or NBFC), preventing misrouted applications and ensuring fast disbursement.

* ## ✨ Key Features
* * **Smart Scheme Recommender:** Uses an AI rule-engine to match user income, project cost, and background to the precise concessional loan scheme instantly.
* **Dynamic Financial Calculator:** Generates accurate EMI, interest, and moratorium breakdowns tailored to specific scheme rules for complete transparency.
* **Geo-Spatial Partner Locator:** Maps and routes users to the nearest eligible Channel Partner (Bank/SCA/NBFC) based on real-time location and fund availability.
